4 · An agent discovers the tools

An agent arriving at this page doesn't guess — it asks. getTools() returns every registered tool with its schema. This (plus a toolchange event) is the entire discovery story. 

const tools = await document.modelContext.getTools();

    

      This JSON is exactly what an AI model gets as its "tool definitions" — the same shape MCP
      servers use. The description and schema are prompt material: write them for the model, not
      for humans.
